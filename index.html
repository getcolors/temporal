Temporal Package Skill

A getcolors Package Skill for a production-oriented single-machine Temporal deployment on DigitalOcean.

Architecture

One guarded Amsterdam Droplet runs PostgreSQL, all four Temporal Server roles, a TypeScript reference worker/API, and Caddy. The Droplet joins the existing regional default VPC discovered at runtime. Cloudflare publishes only the apex HTTPS API.

Pinned software

Temporal Server 1.31.2 and TypeScript SDK 1.22.0, discovered from official release feeds on 2026-08-15.

Operate

./green build
./green create --dry-run
./green create
./green acceptance --reboot

See the repository manual for configuration, backup, restoration, upgrades, logs, and single-node disaster-recovery limitations.
